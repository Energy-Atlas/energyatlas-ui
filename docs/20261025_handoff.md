## What was built

UI updates (`claude/ui-alignment-updates-2de5e1`):

- The ribbon starts with the EnergyAtlas mark alone; the product and project names are gone (the project name stays a
  visually hidden page heading). Decision 0021, section 15.
- View > Panels ticks every page and panel that is on screen, wherever it is docked. Toggling a visible panel docked
  among the pages closes it; showing it again docks it on its home side.
- The ribbon ends with a round initials button (the one round shape, `--radius-round`). Its menu has exactly Account,
  which opens an Account page tab (also in View > Panels), and Log out, which is planned and explains so in the status
  bar. Decision 0021, section 16.

Decisions:

- [0022](decisions/0022-backend-connections-inside-rc.md): no real backend connections in this repository; they are
  built inside RCEnergySimulator once the demo is refined. `feature/agentic` stays unmerged.
- [0023](decisions/0023-mock-server-and-fixture-picker.md): roadmap step 1, option A.

Roadmap step 1 (`feature/mock-services`):

- A mock server in `src/server/` owns the project: domain engine, job runner, browser save. The UI reaches it through a
  transport (`transport.ts`) and the project client (`src/app/service/projectClient.ts`).
- RC's shapes: error body `{success, message, code}` with field errors, a 409 `run_in_progress` for edits during a
  run, and jobs with RC's states and a log. Tasks became Jobs.
- Request states: "Waiting for the server" in the status bar, controls explain why they wait, "unsaved changes".
- Ctrl+Z undoes unsent drafts only.
- Help > Demo conditions: fixtures (New, Partway, Failed stage, Complete), delay, faults, job behaviour, held requests;
  a status-bar chip discloses non-default conditions; URL parameters `fixture`, `latency`, `fault`, `jobs`, `hold`.
